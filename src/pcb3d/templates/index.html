Exporting DXF / SVG from KiCad

PCB3D Studio supports both DXF and SVG vector board files exported from KiCad:

Option A: Exporting DXF

  1. In KiCad PCB Editor, go to File → Export → DXF...
  2. Check layers: Edge.Cuts, F.Cu, and Drill / NPTH.
  3. Ensure DXF Format is set to AutoCAD 2010 or later.
  4. Click Export and drop the .dxf into PCB3D!

Option B: Exporting SVG

  1. In KiCad PCB Editor, go to File → Export → SVG... (or File → Plot → SVG).
  2. Select layers: Edge.Cuts, F.Cu, and Drill / NPTH.
  3. Ensure layers are exported to a single combined file (or default layer groups).
  4. Click Export and drop the .svg into PCB3D!
